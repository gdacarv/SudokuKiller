# Commit Skill
1. Run `git add -A` to stage ALL files (never selectively stage unless told otherwise)
2. Include all asset files, prefabs, and meta files
3. Write a concise commit message describing the feature/fix
4. Run `git status` first to show what will be committed
5. After committing, run `git log --oneline -1` to confirm
6. After confirming, run `git push` to push the commit
